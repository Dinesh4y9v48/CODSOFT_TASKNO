# CodSoft Machine Learning Internship – Projects

This repository contains the **three Machine Learning projects** I completed as part of my **CodSoft Machine Learning Internship**.
#### 1. Customer Churn Prediction.
#### 2. SMS Spam Detection.
#### 3. Movie Genre Classification. 

The projects helped me gain practical experience in **data preprocessing, exploratory data analysis, feature engineering, Natural Language Processing (NLP), model training, evaluation, and prediction** using Python and Machine Learning libraries.

---

##  Projects

### 1. Customer Churn Prediction

**Objective:**
The Customer Churn Prediction project predicts whether a customer is likely to **leave (churn) a service or continue using it**.

**Technologies Used:**

* Python
* Pandas
* NumPy
* Matplotlib
* Seaborn
* Scikit-learn

**Key Steps:**

* Loaded and explored the customer dataset
* Performed data cleaning and preprocessing
* Handled categorical and numerical features
* Performed exploratory data analysis
* Encoded categorical variables
* Split the data into training and testing sets
* Trained Machine Learning classification models
* Evaluated model performance using appropriate metrics
* Predicted customer churn

**Learning Outcome:**
This project improved my understanding of **classification problems, data preprocessing, feature engineering, and model evaluation**.

---

### 2. SMS Spam Detection

**Objective:**
The SMS Spam Detection project classifies text messages into two categories:

* **Spam**
* **Legitimate (Ham)**

This project uses **Natural Language Processing (NLP)** and Machine Learning techniques to identify unwanted messages.

**Technologies Used:**

* Python
* Pandas
* NumPy
* Scikit-learn
* NLP
* TF-IDF

**Machine Learning Models Tested:**

* Naive Bayes
* Logistic Regression
* Support Vector Machine (SVM)

**Key Steps:**

* Loaded and cleaned the SMS dataset
* Preprocessed text messages
* Converted text into numerical features using **TF-IDF**
* Split the dataset into training and testing sets
* Trained multiple classification models
* Compared model performance
* Generated predictions for new SMS messages

**Learning Outcome:**
This project helped me understand how **NLP converts text into numerical features** and how classification algorithms can be used for text-based prediction.

---

### 3. Movie Genre Classification

**Objective:**
The Movie Genre Classification project predicts the **genre of a movie based on its plot/story description**.

The project demonstrates how NLP and Machine Learning can be applied to understand text and classify it into a particular movie genre.

**Technologies Used:**

* Python
* Pandas
* NumPy
* Scikit-learn
* NLP
* TF-IDF
* Support Vector Machine (SVM)

**Key Steps:**

* Loaded and explored the movie dataset
* Cleaned and preprocessed movie plot descriptions
* Handled missing values
* Converted plot text into numerical features using **TF-IDF**
* Split the dataset into training and testing data
* Trained a classification model
* Evaluated the model using accuracy and classification report
* Tested the model with new movie story/plot descriptions

**Learning Outcome:**
This project strengthened my understanding of **text classification, TF-IDF vectorization, and NLP-based Machine Learning models**.
